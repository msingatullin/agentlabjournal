# Публикационный мост: «Пельмени на завтрак» → Agent Lab

## Шаблон ссылки

`https://agentlabjournal.online/{article}.html?utm_source=telegram&utm_medium=channel&utm_campaign=pelmeni&utm_content={post-slug}`

## Редакционный цикл

1. Короткий пост в канале: проблема, наблюдение или новость.
2. Подробная статья Agent Lab: факты, проверка, практический вывод.
3. Один CTA в конце поста: ссылка на конкретную статью.
4. После публикации проверить переход и записать UTM-метрики.

## Ограничения

- Не ставить ссылку в каждый пост.
- Не публиковать неподтверждённые цифры и выдуманные кейсы.
- Не копировать статью дословно.
- Целевой режим: 2 связки в неделю, с пересмотром по Метрике через 14 дней.
