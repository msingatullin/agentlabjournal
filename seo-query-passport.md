# SEO query passport

Заполняется до публикации каждой новой публичной статьи.

```yaml
primary_query: ""
related_queries: []
frequency: unvalidated # НЧ/СЧ/ВЧ только по измеренным данным
intent: ""
region: ""
language: ru
evidence_source: ""
evidence_collected_at: ""
target_canonical_url: ""
parent_pillar_page: ""
internal_link_plan: []
query_to_url_unique: false
canonical_verified: false
structured_data_verified: false
sitemap_included: false
seo_gate: BLOCKED
```

`frequency: unvalidated` означает, что публикация не прошла SEO-гейт до
получения измерения из Yandex Wordstat, Yandex Webmaster, Google Search Console
или утверждённого SEO-датасета. Технические метатеги не заменяют измерение.
