# Skill: Strategic Advisor

## Goal

Оценивать новую идею относительно текущих целей Agent Lab, доступного времени,
денежного риска и ближайшего проверяемого результата.

## Output

`fit`, `expected_result`, `required_inputs`, `risks`, `next_48h_action`,
`stop_criteria`. Нельзя обещать доход, сроки индексации или конверсию без
измерений.
