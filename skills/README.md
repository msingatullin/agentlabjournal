# Agent Lab Skills

Версионируемые инструкции для повторяемых процессов Agent Lab Journal.

Каждый skill имеет одну измеримую задачу, входные данные, ограничения и
выходной контракт. Skills не обходят `seo-query-gate.py`, publication gate,
Yandex recrawl и проверку фактов.

## Skills

- `article-to-distribution.md` — превращает опубликованную статью в набор
  черновиков для Telegram, X/LinkedIn и короткого видео.
- `source-fact-check.md` — отделяет факты источника от гипотез и требует
  ссылки на исходный материал.
- `weekly-funnel-review.md` — шаблон еженедельного анализа публикаций,
  UTM и заявок без выдумывания метрик.
- `strategic-advisor.md` — проверяет идеи через цели, ограничения и текущие
  проекты владельца.
