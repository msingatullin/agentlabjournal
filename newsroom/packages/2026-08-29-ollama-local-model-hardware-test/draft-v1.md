# Какую нейросеть потянет ваш компьютер: выбираем модель Ollama для 8, 16 и 32 ГБ памяти

Локальная нейросеть работает прямо на вашем компьютере: запросы не нужно отправлять в облачный чат, а модель можно запускать даже без интернета. Но первая установка часто заканчивается разочарованием — модель загружается медленно, компьютер начинает использовать файл подкачки, а ответы идут по одному слову. Причина обычно не в Ollama, а в неверном сочетании размера модели, доступной памяти и контекстного окна.

Ниже — не выдуманный «тест трёх компьютеров», которых у нас нет. Это практическая схема выбора, основанная на опубликованных размерах файлов в официальной библиотеке Ollama и документации о контексте. Итоговую скорость всё равно нужно измерить на своём железе.

## Сначала проверьте, сколько памяти действительно свободно

Для локальной LLM важны два ресурса: видеопамять GPU и обычная оперативная память. Если модель полностью помещается в видеопамять, ответ обычно формируется быстрее. Если часть вычислений переносится на CPU и RAM, запуск остаётся возможным, но скорость может заметно снизиться.

Размер файла модели — это нижняя граница, а не полный расход памяти. Дополнительное место требуется служебным данным и контексту диалога. Документация Ollama прямо указывает: увеличение context length повышает потребление памяти. Проверить фактическое размещение модели после запуска можно командой:

```bash
ollama ps
```

В столбце `PROCESSOR` видно, работает ли модель на GPU целиком или частично выгружена на CPU.

## Что выбирать при 8 ГБ

Начните с малых моделей. В официальной библиотеке Ollama файл `llama3.2:1b` занимает около 1,3 ГБ, а `llama3.2:3b` — около 2 ГБ. У Qwen 2.5 варианты `0.5b`, `1.5b` и `3b` занимают примерно 398 МБ, 986 МБ и 1,9 ГБ соответственно.

Для компьютера с 8 ГБ RAM это более безопасная стартовая зона, особенно если встроенная графика использует общую память. Не начинайте с максимального контекста и закройте тяжёлые приложения. Команда для первого запуска:

```bash
ollama run llama3.2:3b
```

Если система уходит в активный swap или перестаёт отзываться, перейдите на `llama3.2:1b` либо `qwen2.5:1.5b`.

## Что выбирать при 16 ГБ

При 16 ГБ RAM можно пробовать Qwen 2.5 7B: опубликованный файл варианта Q4 занимает около 4,7 ГБ. Такой размер оставляет системе запас, но длинный контекст и параллельно открытые приложения способны его быстро съесть.

```bash
ollama run qwen2.5:7b
```

После первого ответа снова выполните `ollama ps`. Если модель в основном работает на CPU, это не ошибка, но ожидание ответа может быть длиннее. Сравнивать модели стоит на одном и том же запросе и с одинаковой длиной контекста.

## Что выбирать при 32 ГБ

На компьютере с 32 ГБ RAM разумным кандидатом становится `qwen2.5:14b`: его опубликованный Q4-файл занимает около 9 ГБ. Это не обещание высокой скорости — она зависит от GPU, пропускной способности памяти и доли CPU-offload. Зато появляется пространство для более крупной модели и более длинного рабочего контекста.

```bash
ollama run qwen2.5:14b
```

Вариант 32B из той же линейки занимает около 20 ГБ только как файл модели. Запуск на 32 ГБ системной памяти возможен не во всех конфигурациях и оставляет мало запаса, поэтому для первого опыта это плохая отправная точка.

## Как провести честную проверку за десять минут

1. Запишите объём свободной RAM и VRAM до запуска.
2. Выберите одну модель и не меняйте context length между повторами.
3. Дайте ей один и тот же запрос из вашей реальной задачи.
4. Зафиксируйте время до первого текста, общую длительность ответа и вывод `ollama ps`.
5. Повторите проверку на соседней по размеру модели.
6. Выберите не самую большую модель, а ту, которая отвечает с приемлемой скоростью и не заставляет систему постоянно обращаться к swap.

Простой ориентир для старта: 8 ГБ — модели 1B–3B; 16 ГБ — сначала 3B–7B; 32 ГБ — сначала 7B–14B. Это консервативная инженерная рекомендация, а не универсальная гарантия: одинаковый объём RAM не означает одинаковую скорость на разных процессорах и видеокартах.

## Главная ошибка — смотреть только на число параметров

Компьютер для локальной нейросети выбирают не по одной цифре. Важны квантование, размер контекста, GPU, свободная RAM и реальная задача. Маленькая локальная нейросеть, которая стабильно отвечает на вашем компьютере, полезнее большой модели, превращающей каждый запрос в ожидание.

Материал подготовлен с использованием ИИ, проверен по официальным страницам Ollama и отредактирован человеком. Напишите в комментариях объём RAM, модель видеокарты и задачу — эти данные позволяют подобрать более осмысленную стартовую модель.
